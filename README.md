# MC Schematics Hide Paid

A simple Chrome extension that hides paid schematics on [minecraft-schematics.com](https://minecraft-schematics.com).

> Why? Because paid schematics are annoying, and everything used to be free!

---

## Features

- Automatically hides paid schematics on the site.
- No controls — it simply hides them.
- Temporary project; not fully finished.

---

## Installation

> [!WARNING]
> This extension is **not published on the Chrome Web Store** and requires Developer Mode to install.

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked**.
5. Select the folder containing this extension.

> [!TIP]
> To view paid schematics again, disable or remove the extension.
